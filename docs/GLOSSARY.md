# Глоссарий новой L2Solo

Определения терминов; подробные ограничения — в [ADR-001](adr/001-domain-model.md) и [архитектуре](ARCHITECTURE.md). Термин не означает обязательный отдельный класс или сервис.

## Участники и владение

| Термин | Определение |
| --- | --- |
| **Account** | Личность реального или виртуального игрока, владеющая персонажами, интересами и социальными связями. |
| **Character** | Игровой персонаж с уровнем, классом, состоянием и инвентарём; принадлежит одному Account. |
| **Main Character** | Выбранный основной Character Account; может меняться независимо от текущего управления. |
| **NPC** | Обитатель мира или сервис, подчиняющийся правилам хроники без долгосрочного AI Account. |
| **Party** | Временная группа Character для совместных действий. |
| **CP (конст-пати)** | Постоянная группа Account с общей деятельностью и собственными ресурсами. |
| **Clan** | Организация CP и/или одиночных Account. |
| **Alliance** | Объединение Clan. |
| **Субъект решений** | Контекстное обозначение Account, Party, CP, Clan или Alliance; не новая сущность. |
| **Социальная принадлежность** | Участие в CP/Clan как сообществе, независимо от официальных игровых слотов. |
| **Формальное членство** | Членство по правилам выбранной хроники, с игровыми лимитами и полномочиями. |
| **Полномочия (Authority)** | Права принимать решения, управлять настройками и отдавать команды. |
| **Контроль Character** | Непосредственный источник команд персонажу: человек или автономное исполнение; конфликтующие контроллеры недопустимы. |
| **Решение организации** | Решение CP, Clan или Alliance. Виртуальный лидер может сообщать его, но не создаёт отдельный AI организации. |
| **Владение ресурсами** | Единственный авторитетный владелец предмета или валюты: Character, Account, CP либо Clan. |

## Поведение и взаимодействие

| Термин | Определение |
| --- | --- |
| **Goal** | Принадлежащий одному субъекту желаемый результат с проверяемым условием достижения; способ получения не входит в определение. |
| **Кандидат на Goal** | Рассматриваемый возможный результат, который субъект ещё не выбрал. |
| **Activity** | Текущее занятие Account или совместная деятельность участников; может не иметь отдельной Goal. |
| **Obligation** | Обязательная для затронутых участников деятельность из допустимого решения организации либо принятой договорённости. |
| **Request** | Предложение или просьба, которая сама по себе не создаёт обязательства. |
| **Команда** | Краткое указание в контексте текущего исполнения, например атаковать или лечить; не новая Goal. |
| **Приоритет Activity** | Числовая оценка текущей важности занятия с ситуационными модификаторами. |
| **Охват Obligation** | Круг участников, для которых действует обязательство; зависит от полномочий и согласия. |
| **Актуальность Activity** | Условия, при которых занятие доступно или требует начала, включая срок и подготовку. |
| **Справочное знание** | Известные правила хроники, рецепты, споты и другие общедоступные сведения; не текущее состояние мира. |
| **Локальное поведение** | Непосредственная реакция на бой, движение, торговлю и другие действия без нового стратегического выбора. |
| **Детальность симуляции** | Различная вычислительная подробность исполнения (возможный Hot/Cold) при сохранении одной личности и реальных последствий. |

**Термины Goal/Activity/Obligation и правила их выбора закреплены в [ADR-002 (Accepted)](adr/002-decision-system.md).**
