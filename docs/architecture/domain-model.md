# Домен: игроки и организации

**Статус:** подробное представление [ADR-001 (Accepted)](../adr/001-domain-model.md). В случае расхождения действует ADR-001. Общая схема — [ARCHITECTURE.md](../ARCHITECTURE.md).

## Участники

| Сущность | Состав и роль |
| --- | --- |
| **Account** | Идентичность человека или автономного игрока, его интересы, персонажи и социальные связи |
| **Character** | Игровой персонаж Account: класс, уровень, положение, экипировка, инвентарь |
| **NPC** | Существо или сервис мира с игровыми и реактивными правилами, без долгосрочной стратегии Account |
| **Party** | Временная группа Character, в том числе из разных организаций |
| **CP** | Постоянная группа Account с собственными решениями и общими ресурсами |
| **Clan** | Объединение CP и/или одиночных Account |
| **Alliance** | Объединение Clan |

## Принадлежность и членство

- Character принадлежит ровно одному Account; у Account может быть несколько Character и сменяемый Main.
- Account состоит не более чем в одной CP; CP входит не более чем в один Clan.
- Для участника CP социальный Clan определяется через CP. При вступлении в CP прежняя непосредственная связь Account с Clan убирается; при выходе сама не восстанавливается.
- CP вступает в Clan и выходит **целиком**. Без CP Account может принадлежать Clan напрямую.
- **Социальная принадлежность** не равна **формальному игровому членству**. Формальное основное место Clan закреплено за Account и представлено Main Character; при его смене сохраняется членство, а игровые права пересчитываются по правилам хроники.
- Академия и другие формальные подразделения работают только в тех хрониках и условиях, где существуют. Alliance связывает кланы, а не напрямую всех их Character.

## Решения и контроль

Account, Party, CP, Clan и Alliance принимают решения в пределах своей роли и компетенции. **Решение организации принадлежит самой организации**; виртуальный лидер — представитель, а не отдельный AI-планировщик.

Человеку доступны команды и настройки по его полномочиям; нельзя одновременно управлять одним Character из двух конфликтующих источников или перехватывать чужого персонажа. Смена режима управления сохраняет личность, имущество и прогресс.

## Владение данными и имуществом

| Данные или имущество | Авторитетный владелец |
| --- | --- |
| Уровень, HP, местоположение, экипировка, инвентарь | Character и соответствующие игровые системы |
| Общий склад персонажей одного Account | Account |
| Общие ресурсы CP | CP |
| Клановые ресурсы | Clan |

При передаче предмета меняется его действительное место хранения; нельзя одновременно считать его доступным в двух складах. Goal, Party и Clan не копируют HP или инвентарь Character. Торговое предложение может существовать без непрерывно работающего стратегического AI продавца.

**Инварианты, формальные лимиты и пограничные случаи закреплены только в [ADR-001](../adr/001-domain-model.md)**. Этот обзор не создаёт новых правил.
